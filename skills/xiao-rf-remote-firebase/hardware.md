# 하드웨어: XIAO ESP32-S3로 리모컨 버튼 누르기

리모컨 버튼 패드에 NPN 트랜지스터를 병렬로 붙여서 ESP32가 버튼을 대신 누르게 만든다.
리모컨의 코드를 복제하지 않고 물리 버튼을 누르는 방식이므로 **롤링 코드 리모컨에서도 동작한다.**

## 부품

| 부품 | 수량 | 비고 |
|---|---|---|
| Seeed XIAO ESP32-S3 | 1 | 다른 ESP32도 되지만 핀 이름이 다름 |
| 2N2222A (또는 PN2222A, 2N3904, BC547 등 소신호 NPN) | 1 | |
| 저항 4.7kΩ | 1 | 베이스 저항. 1k~10k 아무거나 가능 |
| 저항 10kΩ | 1 | 풀다운. 10k~100k 가능 |
| 전선, 브레드보드, 멀티미터 | | |

## 1단계: 버튼 구조 확인 (반드시 먼저)

이 회로는 **버튼 한쪽이 GND이고, 다른 쪽이 풀업된 MCU 입력**인 리모컨에서만 동작한다.

1. 리모컨 케이스를 열고 누를 버튼의 패드(보통 바깥 링과 안쪽 원/링)를 찾는다.
2. **전압 측정** (배터리 끼운 상태): 멀티미터 COM을 배터리 (−)에 대고 두 패드를 잰다.
   - 한쪽 0V, 다른 쪽 ≈ 배터리 전압 → 다음으로
   - 둘 다 0V이거나 흔들림 → 이 회로로는 안 됨 (아래 "안 맞는 구조" 참고)
3. **도통 확인** (배터리 뺀 상태): 도통 모드로 배터리 (−)와 각 패드를 찍는다.
   - 삐 소리 나는 패드 = **GND 패드**, 나머지 = **신호 패드** (트랜지스터 콜렉터를 여기에 연결)
   - 어느 패드도 (−)와 안 붙고 한쪽이 (+)와 붙음 → 이 회로로는 안 됨
4. **동작 확인**: 1kΩ 저항을 끼운 점퍼선으로 신호 패드와 GND를 잠깐 이어본다.
   리모컨 LED가 켜지고 기기가 반응하면 OK. (저항 없이 직접 쇼트하지 말 것)

신호 패드가 3V인데 GND로 당겨도 안전한 이유: 그 3V는 칩 내부 풀업 저항을 거친 전압이라 흐르는 전류가 µA 수준이다.

### 안 맞는 구조일 때

| 구조 | 해결 |
|---|---|
| 버튼이 칩에 전원을 넣는 방식 (한쪽이 배터리 +) | PC817 포토커플러를 두 패드에 병렬 (콜렉터를 전압 높은 쪽) |
| 버튼 매트릭스 (행/열 스캔) | PC817 포토커플러 |
| 12V 배터리(A23/27A) 리모컨 | 원래 배터리 유지 또는 12V 승압. XIAO 3V3로 급전하지 말 것 |

## 2단계: 결선

```
                         리모컨 버튼
                     ┌─────────────────────┐
                     │  바깥 링 (GND)       │
                     │    ┌───────────┐    │
                     │    │ 안쪽 (신호) │    │
                     │    └─────┬─────┘    │
                     └──────────┼──────────┘
                                │ Collector
                              ┌─┴─┐
   XIAO D3 ──[ 4.7kΩ ]──┬──── │ B │ 2N2222A
                        │     └─┬─┘
                     [ 10kΩ ]   │ Emitter
                        │       │
   XIAO GND ────────────┴───────┴──────── 리모컨 배터리 (−) 단자

   XIAO 3V3 ──────────────────────────── 리모컨 배터리 (+) 단자   (3V 코인셀 리모컨일 때)
```

| From | To |
|---|---|
| XIAO D3 | 4.7kΩ → 2N2222A Base |
| 2N2222A Base | 10kΩ → XIAO GND |
| 2N2222A Emitter | XIAO GND |
| 2N2222A Collector | 리모컨 **신호 패드** |
| XIAO GND | 리모컨 배터리 (−) |
| XIAO 3V3 | 리모컨 배터리 (+) — 배터리는 뺀다 |

GND 패드에는 선을 따로 달지 않는다. 리모컨 기판 안에서 이미 배터리 (−)와 붙어 있다.

### 2N2222A 다리 순서

글자 쓰인 평평한 면을 앞으로, 다리를 아래로 두고 왼쪽부터:
- **2N2222A / PN2222A: E – B – C**
- **P2N2222A (ON Semi): C – B – E** (반대)

부품 표면 인쇄를 꼭 확인한다.

## 핀 선택 (XIAO ESP32-S3)

- 기본: **D3 (GPIO4)**. D0, D1, D4, D5도 가능
- 피할 것: D6/D7 (UART TX/RX, 부팅 시 신호가 나가서 버튼이 눌림), GPIO0 (BOOT 버튼)
- D2 (GPIO3)는 JTAG 스트래핑 핀이고 Sense 확장보드의 SD카드 CS라서 피하는 편이 낫다
- 핀을 바꾸면 `RemoteFirebase.ino`의 `#define BTN D3`도 바꾼다

## 3단계: 하드웨어만 따로 테스트

Firebase 없이 트랜지스터 동작만 보고 싶으면 이 스케치를 올린다. 10초마다 버튼을 누른다.

```cpp
#define BTN D3
void setup() { pinMode(BTN, OUTPUT); digitalWrite(BTN, LOW); delay(2000); }
void loop() {
  digitalWrite(BTN, HIGH); delay(400); digitalWrite(BTN, LOW);
  delay(10000);
}
```

## 문제 해결

버튼이 눌려야 하는 순간(D3 HIGH) 신호 패드 전압을 잰다.

| 측정값 | 의미 | 조치 |
|---|---|---|
| 0.2V 이하 | 스위칭 정상 | 누름 시간을 늘린다 (`delay(400)` → 800). 리모컨 전원 확인 |
| 그대로 3V | 트랜지스터가 안 켜짐 | E/B/C 순서, 베이스 저항 결선, 핀 번호 확인 |
| 0.5~2V | 반쯤 켜짐 | 베이스 저항을 줄인다 (4.7k → 1k) |

누름 시간이 짧으면 수신기가 인식을 못 한다. RF 인코더는 누르는 동안 같은 프레임을 반복 송신하고, 수신기는 보통 2~3번 받아야 반응한다.
